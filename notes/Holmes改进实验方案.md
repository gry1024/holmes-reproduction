# Holmes 改进实验方案

16 组训练与 4 组重训基线敏感性扫描均已完成，结果见[实验总报告](../experiments/RESULTS.md)。

## 改动一：多局部证据聚合

原模型只取一个最高局部分数。改为同时参考多个高分位置，减少偶然高分造成的误检：

`分支分数 = 0.5 × 最高分 + 0.5 × 前 3 个有效局部分数的均值`

片段和帧分支均应用该规则；不足 3 个有效位置时使用实际数量，不计 padding。TVR 双查询在逐 token 匹配视频位置时应用同一聚合。Top-k 不要求位置相邻。

## 改动二：查询自适应尺度融合

增加小型网络，根据查询表示预测片段权重 w：

`查询表示（384 维）→ Linear(384,64) → GELU → Linear(64,1) → sigmoid`

`最终分数 = w × 片段分数 + (1−w) × 帧分数`

同一查询对所有候选视频使用同一权重，初始值等于原固定比例。用融合分数训练门控：`总损失 = 原损失 + 0.1 × CE(融合分数 / 0.1, 原标注)`。该损失属于改动二的一部分，结果评价整个改动，不单独归因于门控。

## 原版基线与三组改进实验

| 实验 | 改动一 | 改动二 |
|---|---|---|
| baseline（原版） | 否 | 否 |
| pooling | 是 | 否 |
| gating | 否 | 是 |
| combined | 是 | 是 |

沿用官方预提取特征、模型主体、batch size 128、优化器和学习率配置；原版与三组改进均从头训练，固定 seed=0。覆盖 Charades、ActivityNet、TVR 单查询和 TVR 双查询，共 16 个训练任务。原版在同型号 RTX 5090、同一软件环境补跑，使用与改进版相同的训练循环、数据顺序设置、优化器、学习率和选模规则。

普通版本最多 100 轮，TVR 双查询最多 150 轮，沿用作者早停规则。训练和推理使用相同打分方式。对完整候选库报告 R@1/5/10/100、SumR、耗时和峰值显存。改进效果以同环境重训原版为基准；[官方权重复评结果](../reproduction/RESULTS.md)仅作复现参考。

首轮不搜索超参数。沿用作者验证选模口径；官方包的 val/test 实际相同，因此不声称独立测试泛化。多种子稳定性尚需后续验证。
