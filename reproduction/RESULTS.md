运行环境为 Linux-6.6.87.1-microsoft-standard-WSL2-x86_64-with-glibc2.35，Python 3.11.15，PyTorch 2.0.1+cu117，GPU 为 NVIDIA GeForce RTX 4060 Laptop GPU。表中耗时包含评测批次的数据读取、视频／文本编码、全候选打分、排序及指标计算，不包含下载、特征转换和模型加载。显存为 PyTorch 峰值已分配显存，不含驱动等额外占用。

作者代码版本为 `73bbbfcfca241418507a9a46691f0cb834e31d8b`。将数据路径、输出路径适配到本机，数据加载 num_workers=0，PyTorch CPU 线程数为 4。模型结构、特征预处理、评测 batch size、打分权重及召回率计算沿用作者配置。

各结果 JSON 记录权重 SHA-256、checkpoint 自带参考结果及配置差异。数据 manifest 记录压缩包 SHA-256、CRC 检查、查询／视频集合校验，以及特征转换逐值和帧顺序检查。

本次完成范围是四份公开权重的完整检索评测，未重新训练模型、消融模型或特征提取器。作者的 Python 版本与 GPU 和本机不同，完整环境差异与重跑命令见 [README.md](README.md)。若 val/test 集合相同，分别运行只用于核对入口一致性，不代表在两个独立数据集上验证。
